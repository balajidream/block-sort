# Block Sort

## Core loop
- A wooden shelf holds vertical 4-block slots.
- Every glossy cube has both a saturated color and an embossed icon: diamond, star, triangle, coin, heart, or moon.
- Tap a source slot, then a destination. The matching top run moves if the destination is empty or has the same top color and enough room.
- A full four-block monochrome slot clears with a pop and confetti. Clear all blocks to finish.
- Early levels are unfailable; undo is available and a single extra-slot booster can recover a tight board.

## Progression
- Levels 1–10 use two colors and three slots; later levels add colors and tighter layouts.
- This first slice has a persistent 12-level grid, coins, locked/cleared/current states, and a small workshop preview.

## Art direction and performance
- Portrait 9:19.5, warm dark walnut background, lighter oak shelves, soft vignette, and high-contrast candy blocks.
- The game is Unity 6 / URP-ready and renders simple 2D sprite-style presentation for mobile readability.
- Blender 4 scripts generate the rounded block, wooden slot, and UI ornament sprites; all assets are lightweight and regenerable.
